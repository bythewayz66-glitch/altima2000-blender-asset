ALTIMA2000 viewer

Everything below runs in the browser — no Blender, no plugin. The model, the 2,130-part manifest and the 27-step teardown animation are the same files that ship in the repo.

Mouse

  • Left drag — orbit (rotate)
  • Wheel — zoom
  • Right drag / two-finger drag — pan
  • Click a part — select it and read its manifest record
  • Hover a wire — the trace runs along it, end to end

Keyboard

  • Space — play / pause the teardown animation
  • F — fit the car in view  ·  R — auto-rotate
  • W — wireframe  ·  X — x-ray  ·  T — live trace
  • Esc — clear selection  ·  H — hide selected
  • 1 / 2 / 3 — Parts / Wiring / Modules tab

Views

  • Explode — pulls every part apart along the 27-step sequence
  • Step — explodes the sequence one step at a time
  • Pull this part off — ejects the selected part individually
  • Wiring tab — 31 harness toggles plus hoses and tie straps
  • Modules tab — isolate any of the 7 module assemblies
